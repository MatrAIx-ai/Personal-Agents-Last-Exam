instructions at the start of **every** session (S1–S4) of a designated hinted run, identically for
all three reference models. It is never shown in ordinary (unhinted) rollouts. In the local stand-in
runner this is `run.cjs --hinted`, which passes it to the agent adapter as `ctx.hint` and records it
in the transcript with `channel: "hint"`. The final position will follow the LifePack harness release.

The hint names records that already exist before S1 and does not quote, paraphrase or prescribe.
