## 4. What makes this distinct and personal

- **Personalization insight (required):** The same summary request and results call for different primary comparisons depending on the researcher's earlier choice of sample size.
- **Decisive context and trigger (required):** The trigger is the exact `2026-06-08T09:00:00-04:00` request in Section 3. The agent can discover the researcher's chosen primary comparison in the user–agent conversation dated `2026-05-29T14:00:00-04:00`, available in the simulated conversation history before all three sessions. The common project note identifies a run replacement but does not select a primary sample size.
- **Generic assistant mistake (required):** A capable non-personal assistant might make the newer `n=1000` result the main comparison or combine it with an `n=600` result because the final request says “latest records.” Either misses this researcher's primary comparison; mixing settings also gives a misleading comparison.
- **Different user, different action (required):** Keep the final request, all session messages, run records, event times, workspace, and the safety and reporting constraints identical. For the other researcher, it is completed A 99.0% (1,980/2,000) versus completed B 96.0% (480/500) at `n=1000`. The same non-primary results may be included as clearly labeled background.
