Doodle screenshots come from public help pages, not a fabricated logged-in account. [Capture metadata](references/captures.json) records URLs, dates, browser and viewport. They are review references outside runtime assets, not a branding/pixel-match target. Meeting Poll intentionally uses trusted fixed identities, private participant replies, explicit yes/if-needed/no, true withdrawal, app-local notices, retained cancellation history and no automatic organizer yes vote. It does not implement Doodle email/calendar delivery, public links or premium vote-on-behalf. These differences follow the approved synthetic scope. The reference deletion workflow is compared to cancellation, not claimed as identical functionality.
