# M1 validation

This is the first-runnable milestone of #40, not complete M2/M3 acceptance. No paid model trial, human provenance review or independent reproduction is claimed.

Run from the public checkout:

```sh
node --test apps/tablewise/tests/*.test.cjs
node runtime/cli.cjs verify --app apps/tablewise --output .artifacts/tablewise-public.json
node apps/tablewise/examples/run-connected.cjs
node apps/tablewise/tests/browser.cjs
npm run test:web
```

Browser checks use the root pinned Playwright install and Chromium; install development dependencies as described by the public runtime. `PLAYWRIGHT_MODULE` can point to an existing compatible installation. The browser script creates a separate temporary state/run and closes it after checking; it does not reset the user preview.

Coverage: published price/minimum arithmetic; hold expiry at equality; protected capacity; stale price previews; current trusted authority/revocation; strict-gap conflict; real amendment and failure rollback; immutable original receipts; source-backed partial/full refunds and payment-ID deduplication; group inquiry vs commitment; actual Mail record and original attachment readback; unchanged-ID retry; denied delivery preserving booking; Core optimistic versions/persistence/reset; historical dates; desktop/mobile GUI.

Local reproducible reports are written under `.artifacts/` (excluded from git). A final submission will copy a reviewed evidence index to `docs/validation/` after M1 review. Node 18 and base-runtime compatibility remain to be run for PR submission. The shared Web Host change only serves an optional declared package-local CSS file, using the same path checks as its page/controller; it needs Infra review, as does the new parent-resource map.

Source fixtures and menus are generated by `python3 apps/tablewise/scripts/build-package.py`; regenerate public contracts with `node runtime/build-contracts.cjs`. Changing code invalidates older package-hash reports. The approved proposal remains unchanged; progress belongs in this file and PR comments/description.
