# Home Repair Slots Web Host

The App uses the shared stylesheet only. The labelled navigation shows the current screen and count of readable bookings. The slot table compares provider, local appointment window and all-inclusive price. Review and booking pages expose structured records; the booking page shows only recorded dated actions for that booking.

See the [App README](../README.md) for setup and the [evidence index](../evidence/README.md) for the real Chromium run. The Web Host uses a bound Agent MCP connection over the same Core data. Scenario events, seed import and reset stay on the separate Infra interface. Nothing is sent to a provider; this UI has no real booking, payment or chat.
