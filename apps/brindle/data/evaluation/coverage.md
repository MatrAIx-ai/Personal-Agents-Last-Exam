# Brindle delivery dataset: date coverage

Generated by `node apps/brindle/dev/coverage.cjs`. Run it from the repository root. With --check it compares with the committed report. Do not edit by hand.

- Scope: Environment coverage of the delivered evaluation seed data/evaluation/seed.json, read at its clock. Only the seven record kinds count, each on one date field. Due times are listed apart. Activity rows are not counted, because each repeats an act that a counted record already dates.
- Time zone: `America/New_York`. A timestamp counts on its calendar day in America/New_York after normalizing its UTC offset. A date-only field (payments[].pay_on) is a day in America/New_York. A missing or invalid date is excluded and listed.
- Window: 2025-01-01 to 2026-12-31. Seed clock: `2026-12-31T23:00:00-05:00`.
- Provenance: 1548 synthetic rows, 0 real, 0 mixed (dataset `brindle-evaluation-2025-2026`). Counts are of the counted rows. Every record is synthetic: Brindle models no real issuer or website, so there is no real source to collect or to anchor.
- App records (the count that `env.load_seed` returns): 1500. Stories in the manifest: 1220.
- Not counted: 1949 activity rows. Each activity row repeats a write, an event or an effect that a counted record already dates.
