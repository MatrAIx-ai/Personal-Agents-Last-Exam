# Benchline delivery dataset: date coverage

Generated by `node apps/benchline/dev/coverage.cjs`. Run it from the repository root. With --check it compares with the committed report. Do not edit by hand.

- Scope: Environment coverage of the delivered evaluation seed data/evaluation/seed.json, read at its clock. Only the seven record kinds of the plan count, each on the date field of an act that happened. Planned times are listed apart. Activity rows are not counted, because each repeats an act that a counted record already dates.
- Time zone: `America/New_York`. A timestamp counts on its calendar day in America/New_York after normalizing its UTC offset. A missing or invalid date is excluded and listed.
- Window: 2025-01-01 to 2026-12-31. Seed clock: `2026-12-31T23:00:00-05:00`.
- Provenance: 1707 synthetic rows, 0 real, 0 mixed (dataset `benchline-evaluation-2025-2026`). Counts are of the counted rows. Every record is synthetic: Benchline models no real cluster or website, so there is no real source to collect or to anchor.
- App records (the count that `env.load_seed` returns): 2298. Stories in the manifest: 640.
- Not counted: 426 activity rows (Each activity row repeats a write, an event or an effect that a counted record already dates.) and 307 run plans (A run plan is world data that the cluster gives, and the App never shows it.)
