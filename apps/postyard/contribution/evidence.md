# Postyard delivery evidence

This delivery is MCP-only. `contribution/gui.json` declares a reviewer placeholder. No business page is shipped, so there are no GUI screenshots. The commands below run from a checkout that contains `runtime/`.

```sh
npm test --prefix apps/postyard
node --test apps/postyard/tests/runtime.test.cjs
node apps/postyard/examples/run.cjs
node apps/postyard/scripts/coverage.cjs
node apps/postyard/scripts/coverage.cjs --output /tmp/postyard-coverage.json
npm run app:verify -- --app apps/postyard --output .artifacts/postyard-verify.json
node --test runtime/tests/clock.test.cjs
npm test
```

`npm test --prefix apps/postyard` is the package suite: `tests/business.test.cjs` and `tests/scope.test.cjs`. It does not import `runtime/`. `tests/runtime.test.cjs` is the host suite and runs from a checkout that contains `runtime/prepare.cjs`. The isolated verifier runs `tests/business.test.cjs` and `examples/run.cjs` with a stripped environment. The copied package used by `app:verify` contains the App only.

Observed on Node v18.20.8, v22.23.5, v22.23.4, and v24.22.3: the package suite passed 39 tests, and `tests/business.test.cjs` passed 16 of those on its own. The host suite passed 1 test on the same three versions. `examples/run.cjs` printed `{"app":"postyard","notes":1,"id":"ac-0007:n1"}`. `examples/confirm.cjs` printed the fixture (a) draft `ac-0001:p13` with status `pending_owner_confirmation`, slug `tidewater-gatekeeping`, and `person_id` `person-tomas`. `app:verify` passed 43 checks on each of those Node versions (runtime 1.6.0, Core API 1.2.0). `runtime/tests/clock.test.cjs` passed 7 tests, including the eight-app clock check. The repository suite passed 22 stages. The live `package_sha256` is recorded in the PR description.

`node apps/postyard/scripts/coverage.cjs` writes `contribution/coverage.json`. `--output` writes the same report to another path. The run used for this note counted 121 included post, note and follow rows, `excluded_count` 2, `distinct_dates` 95 Los Angeles calendar dates, and `empty_months` empty, with every month from 2025-01 through 2026-12 represented. The two excluded rows are the scheduled post and scheduled note in fixture (b), which have no `published_at`. The report also records source hashes, per-source totals, and the earliest and latest included dates. Time zone `America/Los_Angeles`. Every row is synthetic. Postyard has no external archive, so November 2026 is synthetic in the same way as the other months. Fixture (a) stops at `2026-02-09T20:40:00-08:00`. Fixture (b) is `examples/task-data/embargo/`. `examples/dataset/later-2026/` holds March through December 2026 and is loaded only at `2026-12-31T18:00:00-08:00`.

The Forkyard join check is outside the package tests:

```sh
node apps/postyard/scripts/check-forkyard-join.cjs /path/to/forkyard-checkout
```

Against Forkyard commit `e9fe739b0b6af11d3805756a4916c028cf41bb4e`, a document that keeps `actor_account_id` `ac-0001` produced no `linked_post` subject. The same document with `actor_account_id` rewritten to `fy-tomasreyes` produced `linked_post` for `person-ingrid`. Against Forkyard `80417c59460dff88d383f9e2cc5da14186ef6ef5`, both documents join. `linked_post` is `person-ingrid` because the post names Ingrid, and the companion revision keeps `person-tomas`. The same native join holds on branch head `2500aa0c1a7279e2f89a547fa75cfd9d81132919`. Task #74 needs no actor rewrite. A snapshot limited to Tomás-authored Forkyard objects omits a `linked_post` that lives only on a Ship-authored comment. See the README for the mapping.

This dataset work follows the evidence policy adopted on 2026-11-25, recorded in `docs/submission-evidence.md`. The added pieces are the monthly coverage report, the later-2026 partition, fixture (b), and the date-rule tests.
