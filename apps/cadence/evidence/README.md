## 2. Declared App dependency: Mail 1.3.0 (send-only notices) and the agent-side Calendar flow

`mail-notice-trace.json` is written by `node apps/cadence/examples/mail-notice.cjs apps/cadence/evidence/mail-notice-trace.json` and records 20 checks over real MCP processes (Cadence, Mail and Calendar instances in one run; the Messaging service as a separate publishing process):

- `classes.cancelled_by_studio` applied by Infra to Thursday's Strength 60; Mail and Calendar clocks advanced to the session time with `env.advance_time` before any delivery or write.
- The host-run publisher reads the committed reservation over the Agent connection and publishes through Messaging; the receipt event is `router-a512ddbb5d54364c9d4f3bea7e787516`, and Mail's record `router-a512ddbb5d54364c9d4f3bea7e787516` holds the notice unread with the title from the proposal's example. Cadence's data and version are unchanged by publishing (no notice status is stored).
- The agent cancels the Calendar entry with `calendar.cancel`, books a replacement with `reservations.preview` and `reservations.confirm` (rsv-1 on ci-7752, included in the trial) and creates its Calendar entry with `calendar.create`; the Calendar state shows the Thursday entry cancelled and the replacement confirmed.
- A publisher configured without a recipient grant is rejected with `recipient_not_authorized`; Mail and Cadence are byte-identical before and after.
- A replay of the same `request_id` returns the first receipt with `duplicate: true`; a new request ID for the same notice deduplicates on the CloudEvents `(source, id)`; Mail's message count does not change.

The Messaging configuration is `examples/router.json` (publisher `cadence`, account `acct-amara`, one grant to Mail account `mail-amara` on `channel.email`). The wire schema copy `schemas/router-message.schema.json` is byte-identical to Mail's; `tests/business.test.cjs` validates every notice kind against it and against `email-payload.schema.json`. Calendar is reached only by the agent's own tools; Cadence sends nothing to Calendar.
