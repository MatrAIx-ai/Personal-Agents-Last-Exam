# Bellnote delivery evidence

This directory holds the evidence asked for by the repository's submission evidence contract (`docs/submission-evidence.md`, added to `main` after this App's plan was approved): GUI workflow sequences, a comparison with the reference products, demonstrations of the delivered dependency and a dataset coverage report. For an approved proposal the contract asks that added delivery work be recorded. This evidence is that record. It adds no workflow, and the App's behaviour, tools, schemas, events and fixtures are unchanged by it. The evidence is for review and is not loaded at run time: it is not an App asset and not part of the media budget.

- **App:** `bellnote` 1.0.0. App code, page, tools, schemas and fixtures are unchanged from commit `9f1bf99`; this directory, its scripts and documentation were added after it. Approved scope: [`proposals/environment/bellnote.md`](../../../proposals/environment/bellnote.md).
- **Host and runtime:** public runtime 1.6.0 (Core API 1.2.0) at base `a4bce02`, shared Web Host `runtime/web/server.cjs`; Mail 1.3.0 (`examples/apps/mail`).
- **Browser:** Chromium 141.0.7390.37, headless, through Playwright 1.56.1. Viewport 1280×720 for the sequences and 390×844 for the phone frames.
- **Run and account:** run `bellnote-evidence`, profile `sandbox`, fresh from `fixtures/reference.json` at Tuesday, November 17, 2026 07:00 America/Los_Angeles. The account is `bellnote-maya` (Maya Chen, a fictional guardian), and all data is synthetic. A second fresh run with profile `scenario` is used for the read-only frame.
- **Node:** 22.23.1 for the captures. Every script was also run on 18.20.8 (see [VALIDATION.md](../VALIDATION.md)).
