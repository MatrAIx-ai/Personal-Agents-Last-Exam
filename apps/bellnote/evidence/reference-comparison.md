# Reference products and Bellnote, workflow by workflow

The approved plan names two workflow references: ParentSquare (forms, school notices) and the PowerSchool parent portal (attendance, guardian records, meal balances). They inform the shape of the workflows only. Bellnote has its own name and look and uses only fictional data, and it copies no text, branding, icons or data from either product.

**No third-party image is copied into this repository.** None of the pages below grants a licence to redistribute its images, so each one is referenced by URL. The description says what the page showed on the retrieval date. Only public, vendor-published pages were used: product listings, product pages, a vendor-hosted feature sheet and the vendor's public documentation. Nothing was logged into, signed up for or scraped. Every URL below returned HTTP 200 when retrieved on **25 November 2026** (America/Los_Angeles).
