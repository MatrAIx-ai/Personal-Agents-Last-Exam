# Source inventory

- Approved scope: upstream PR #6, proposal commit
  `fec36374e5aec9a1cd298306777eee68ce715122`.
- Reference prototype inspected: `genglinliu/PM-agent-sharable`, commit
  `cb8cdc189e6f891894649584458f7e8c2813e2c3`, especially
  `adapters/are_finance/ledger.py`, `market.py` and `apps.py`. The prototype demonstrates
  integer-cent accounting, exact previews, confirmations and replay receipts.
- This package implements a new PALE state format and finance adapter. It does
  not copy or import the prototype's ARE modules, UI, market responses, account
  fixtures, agent controller or saved sessions. Before importing any prototype
  source/assets later, record compatible ownership/licensing and
  preserve required notices. The inspected repository has no top-level license.
- New Finance code and generated fictional scenes use the repository's
  MIT license. Dataset realism and provenance review remain pending.
- `service.cjs` and the Core state-envelope schema follow PALE's MIT reference
  package. Shared schemas under `schemas/` are generated copies of PALE's
  canonical contracts; regenerate with `npm run contracts:build` at repo root.
- No collected market data, images or other content assets are bundled: zero assets,
  zero decoded asset bytes. This is separate from the source package's size.
- All six instruments, 360 daily observations and 12 announcements are authored
  synthetic records generated by `scripts/build-fixtures.py`. They do not copy
  external market data or imply real financial returns.
- The GUI uses PALE's shared MIT DOM helper and stylesheet through the public
  Web Host. Its Finance controller and canvas chart are original package code.
- The optional collector independently adapts the prototype's read-only feed
  approach without importing ARE. It requests Yahoo public chart JSON, or the
  Alpha Vantage IBM daily demo. Live responses are never part of the synthetic
  fixture license; local capture and runtime dataset metadata record provider,
  URL, actual observation/collection times, raw bytes and hashes. Redistribution
  of collected data remains subject to source terms and human review.
